# Freedom File Manager — الإصدار 0.2.0

تطوير تراكمي فوق الإصدار 0.1.0 داخل المستودع نفسه.

## ما أضيف في 0.2.0
- تصفح فعلي للمجلدات التي يمنحها المستخدم عبر SAF، مع حفظ إذن المجلد.
- الإبقاء على تصفح التخزين المشترك عبر MANAGE_EXTERNAL_STORAGE.
- تكامل أولي مع Shizuku: اكتشاف الخدمة، طلب الإذن، واختبار هوية العملية بأمر id.
- فحص قواعد SQLite للقراءة فقط: عرض أسماء الجداول والفهارس والمشاهدات والمشغلات وتعريفاتها.
- عارض HEX للقراءة فقط يعرض أول 512 بايت مع العرض النصي المقابل.
- الملفات الأصلية لا تُعدّل في أدوات الفحص الحالية.

## ملاحظات مهمة
- Shizuku يجب تشغيله ومنحه الإذن من تطبيق Shizuku. زر التطبيق يفحص الاتصال والصلاحية.
- هذه الدفعة تضع طبقة الاتصال الأولية فقط؛ لم نفعّل بعد تصفح Android/data أو Android/obb بواسطة Shizuku. سيتطلب ذلك اختباراً على الجهاز، لأن الوصول الفعلي يتأثر بإصدار Android وسياسات النظام.
- Shizuku بصلاحية ADB shell ليس Root، ولا يمنح تلقائياً الوصول إلى بيانات التطبيقات الخاصة مثل /data/user/0.
- SAF يتيح الوصول إلى المجلدات والملفات التي يختارها المستخدم فقط، وفق ما يسمح به منتقي النظام.
- عارض SQLite قد لا يقرأ قواعد البيانات المشفرة أو قواعد WAL غير المكتملة.
- لا توجد في هذا الإصدار عمليات حذف أو نقل أو كتابة HEX/SQLite.

## البناء على AndroidIDE
المتطلبات: Android SDK 35 وAndroid Gradle Plugin 8.6.1 وGradle 8.7 أو إصدار متوافق.
افتح المشروع، نفّذ Gradle Sync، ثم Build/Run. يجب توفر اتصال إنترنت لتنزيل مكتبات AndroidX وShizuku.

## التالي
المرحلة التالية: واجهة عمليات الملفات، بحث وفرز، معاينة نصوص، دعم ملفات SQLite ذات WAL مع نسخ احتياطية، ثم تنفيذ أوامر Shizuku على مسارات مختارة بعد اختبارها على Android 14.
